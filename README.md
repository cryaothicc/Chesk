# Chesk

Play chess or checkers on an interactive 3D board. Share a device in **Pass & Play** mode or choose **Vs AI** to play against the computer.

[Open Chesk on GitHub Pages](https://cryaothicc.github.io/Chesk/)

## Run locally

Open `index.html` in a browser with WebGL support. No install or build step is needed. Keep an internet connection so the page can load its libraries from CDNs.

## How to play

- Choose chess or checkers. Select a piece to highlight its available moves, then pick a destination.
- In checkers, continue with the same piece when another jump is available.
- Drag to rotate the board. Use the game controls to switch modes or reset the match.

The board uses Three.js and OrbitControls. Chess rules use chess.js, and animations use GSAP.
